# 🤖 Document AI Assistant

A local AI-powered PDF chat assistant built with RAG, Ollama, LangChain, FAISS, and Gradio.

## Features
- Upload any PDF
- Build vector index locally
- Ask questions about the document
- Streaming AI responses
- Local LLM with Ollama
- No paid API required

## Tech Stack
- Python
- LangChain
- FAISS
- Gradio
- Ollama
- Qwen

## How it works
1. Upload a PDF
2. Build an index
3. Ask questions
4. Get grounded answers from the document

## Run locally
```bash
pip install -r requirements.txt
python app.py
